# Linux Command Line System Management

This Bash script showcases fundamental Linux command-line operations for system administration. It covers user management, file system manipulation, process monitoring, and basic networking commands, reflecting skills tested in the CompTIA Linux+ XK0-005 exam.

## Language

`bash`

## How to Run

Save the code as `linux_sys_admin.sh`, make it executable (`chmod +x linux_sys_admin.sh`), and run it from your Linux terminal (`./linux_sys_admin.sh`). Some commands may require root privileges (use `sudo`).
